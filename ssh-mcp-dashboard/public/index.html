🔐 私钥和公钥是什么？（30 秒看懂）
🔒
公钥 = 锁芯
放在服务器上，可以公开给任何人，泄露了也没关系。
🔑
私钥 = 唯一钥匙
只留在你自己的电脑（~/.ssh 目录），相当于密码，绝不能发给别人。
🤝
登录时发生什么
服务器用你放的锁芯出一道题，只有你的钥匙能解开 —— 所以不用输密码，密码也不会在网上传输。
一句话流程：生成密钥对 → 把 .pub 公钥贴到服务器 → 本机用私钥自动登录。私钥永远不上传。
